# Contributing

Bug reports, design feedback, and focused pull requests are welcome.

For a problem report, include the command or browser action, expected behavior, actual behavior, Node version, and a minimal synthetic bundle. Never attach sensitive records or credentials.

Before submitting code, read the existing implementation and tests, keep changes focused, add tests for changed behavior where appropriate, and run:

```sh
npm run check
npm test
```

Describe the problem, the change, and validation in your pull request. Discuss substantial design changes in an issue first.
