# Roadmap

These are proposed milestones, not adoption claims or delivery promises.

1. Validate the first use case with five people who need to trace an AI-assisted decision. Success: each can identify a deliberately missing step without guidance.
2. Completed: adopt Apache License 2.0 and publish contribution guidance. Next: review small, reproducible community contributions.
3. Document one real, permission-cleared workflow with reproducible inputs, output and limitations. Keep the synthetic example as the safe default.
4. Add explicit revision relationships, filtered graph navigation and trusted-digest UX after observing actual use. Preserve the existing format or provide migration tooling.
5. Explore connectors only when repeated demand justifies them. Publish one canonical tool per job and reference shared objects rather than copy repositories.
6. Measure returning users, completed verifications, resolved external issues and outside contributions. Stars and followers are secondary signals.

Public architecture: the account profile is the entry point; Memory Window is the focused inspector; Victoroff OS is the broader experimental platform. Private work stays private. No automatic publication of chats or personal memory is planned.
